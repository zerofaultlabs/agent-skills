# Validation protocol

Keep historical captions and expected answers outside the production skill.

## Blind generation

1. Build a brief from source facts available before publication: photos, event details, visual text, reel summary, theme, or CTA.
2. Exclude the published caption, engagement data, comparison notes, and prior test results.
3. Generate the complete caption through the production workflow.
4. Save it with the source identifiers and a timestamp or checksum before opening the published caption.

## Reveal and compare

Compare:

- primary angle and opening;
- facts retained or omitted;
- voice, length, and paragraph structure;
- relationship to the visual;
- emoji restraint;
- CTA choice;
- unsupported additions;
- whether a question or verification flag was necessary.

Classify differences as equivalent creative variation, useful alternate, meaningful mismatch, or unresolved human preference. Refine the skill only when a mismatch reveals a reusable routing, safety, structure, or voice problem. Keep case-specific answers in the external test record.
